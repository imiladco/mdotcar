Mentoring widget for mdotcar.com.

== Description ==

Provides the mentoring widget used on mdotcar.com. This release contains the
plugin foundation: environment checks, autoloading, versioned upgrade routine,
i18n/RTL-ready assets and the widget registration pipeline.

== Installation ==

1. Upload the `mdotcar-mentoring` folder to `/wp-content/plugins/`.
2. Activate the plugin through the *Plugins* screen in WordPress.
